# Manim Style Math

> Origem: [AI Style Atlas](https://www.futurepedia.io/resources/ai-style-atlas/view). Este arquivo é a cópia local do estilo, para não depender do site.

## Visual
Visual da biblioteca Manim: fundo preto, vetores nítidos, paleta contida em azul, verde-azulado, amarelo, vermelho e verde, notação matemática com serifa, eixos, curvas e chaves com rótulo.

## Como os componentes aplicam o tema
Renderizado com Manim (fase 3). O acento do tema substitui o azul principal.
